# הוכחת רעיון - הוצאת מידע ממערכת סגורה

## רקע פיזיקלי לפרויקט

## ציוד נדרש
1. 2 ארדואינו
2. חוטים זכר-זכר וזכר-נקבה
3. 2 דיודות שוטקי

### ציוד אופציונלי:
1. 2 לדים בצבעים שונים
2. 2 נגדים של 200 אוהם
3. 2 Breadboards

## שלב 1 - הוכחת הרעיון הבסיסי
### שלבי הבנייה
בשלב הראשון נוכיח שהרעיון בכלל אפשרי:
1. ניקח ארדואינו.
2. ניצור סליל באמצעות חוטי זכר-נקבה כך שיהיו לו 3 לולאות.
3. נחבר את הסליל מפין דיגיטלי, למשל D7, לנקודה ב-Breadboard.
4. נחבר מנקודה זו לד (אדום) לנקודה בשורה אחרת ב-Breadboard.
5. נחבר מהנקודה השנייה נגד של 200 אוהם לנקודה שלישית בשורה אחרת ב-Breadboard.
6. נחבר מהנקודה השלישית חוט לאדמה (GND) של הארדואינו.

עד כאן המערכת הסגורה שלנו, נבנה כעת את ה"מקלט" שיאזין לה:
1. ניצור עוד סליל באמצעות חוטי זכר-נקבה כך שיהיו לו 3 לולאות.
2. נחבר את הסליל בצד אחד לאדמה (GND) של הארדואינו, ובצד השני לאנודה של דיודת שוטקי (לחלק שרחוק מהפס האפור).
3. את הקתודה של הדיודה (החלק הקרוב לצד האפור) נחבר לפין אנלוגי, למשל A0.
